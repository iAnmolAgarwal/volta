## Notes

- **Reference level.** The hour blocks are dummy-coded with `blk_night` (hours 0 to 5) left out: a row with every `blk_` column at 0 is a night hour, and the model's intercept is the night base load.
- **No timestamp column.** Hour information enters only through the block flags, so QuickML cannot pick up the date and extrapolate it into the test window.
- **Algorithm.** Choose a linear algorithm (linear or ridge regression). Tree ensembles cannot extend the cooling line past the hottest training temperature; see `docs/model_report.md`.
- **Endpoint input.** Send `build_features(df)[QUICKML_FEATURES]` for each forecast row, in this column order.
